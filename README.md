## Frequently Asked Questions

### Is the toolkit compatible with Windows 11?

Yes. The Apex Legends Advanced Toolkit is fully compatible with both Windows 10 (version 1909 and later) and Windows 11. All features have been tested on the latest stable builds of both operating systems.

### My antivirus is blocking the installer. What should I do?

Some antivirus programs may flag utility applications as potentially unwanted programs (PUPs). This is a common false positive. You can temporarily disable your antivirus during installation or add the downloaded file and installation folder to your antivirus exclusion list.

### How do I update the toolkit to the latest version?

The toolkit includes an integrated update checker. Navigate to **Settings > About** within the application and click **Check for Updates**. If a newer version is available, you will be prompted to download and install it automatically.

### Can I reset all settings to default?

Yes. Open the toolkit and go to **Settings > Advanced > Reset to Defaults**. This will restore all configuration options to their original state. Your backed-up profiles will not be affected.

### Does the toolkit run in the background during gameplay?

The overlay and monitoring features can run alongside Apex Legends without significant resource impact. If you prefer a completely clean environment, you can disable the overlay from the **Settings > Overlay** menu or close the toolkit entirely before launching the game.
